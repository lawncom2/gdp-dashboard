# 📝 네이버 블로그 글 작성 비서

네이버 블로그 스타일의 글을 쉽게 기획하고 작성할 수 있도록 도와주는 Streamlit 앱입니다.
주제와 키워드만 입력하면 자연스러운 아웃라인을 제안하고, 사람이 쓴 것처럼 읽히는 초안을 자동으로 완성해 줍니다.
또한 각 단락의 분위기에 어울리는 이미지 프롬프트와 시각 초안을 함께 생성해 이미지까지 준비할 수 있습니다.

### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```
